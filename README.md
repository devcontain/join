# JOIN – Task Management Application

JOIN is a web-based task management application developed as part of my frontend development training.

The project allows users to organize tasks, manage contacts, assign priorities and track progress using a Kanban-style board.

## Technologies

- HTML5
- CSS3
- JavaScript
- PHP
- SQL database
- REST-style API

## Features

- Kanban board with task management
- Create, edit and delete tasks
- Contact management
- Task priorities and deadlines
- Dashboard with task statistics
- Guest login for exploring the application
- Individual demo accounts with server-side data storage

## Backend Development

I extended the original frontend project with my own PHP backend and database integration.

This includes user authentication, session management, API endpoints and persistent storage of project data.

The guest mode remains available without requiring a personal account.
